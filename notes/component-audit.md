# Component audit

Audit scope: shared UI exports and layout/auth/API-key compositions. All retained public UI values have actual rendered examples, checked by TypeScript symbol identity.

## Decisions

- ToastCard adds a plain-text timed capsule with an isolated ToastPreview in Data & feedback; the demo replaces/replays one current toast, with no API side effects.

- SelectionCard is a controlled shared option button reused by catalogue category navigation. Cards includes a searchable interactive example with selected, unselected and disabled options; native keyboard behavior and theme contrast are browser-tested.

- Removed unused ThemeToggle state wrapper; retained ThemeToggleButton as the previously requested showcase-only compact theme control.
- Removed OAuthOptionsCard (showcase-only, redundant with PanelCard/PrimaryCard) and its unused CSS.
- Retained MenuList as a reusable selectable menu, and KeyValueCard as a compact description-list row. Neither needs to be forced into routing/profile screens with different semantics.
- Consolidated provider logo rendering into OAuthProviderIcon; OAuth buttons and connected-provider cards reuse it.
- Avatar removal uses shared Button. Native file labels, navigation links, switch tracks and popup rows retain their semantic controls; they are not interchangeable with generic action buttons.
- Added missing PrimaryCard, UserAvatar, AvatarUploadField, CopyField, connected-provider and API-key previews. BrandBanner is separately searchable. StatusCard and all status wrappers are represented.
- API-key examples use the real feature component with local sample state, never API hooks. OAuth samples open the auth preview. Account history and uploads do not modify browser account history or saved profiles.
- Localized labels and organized searchable categories. Retired unused catalog group styles and updated key/value geometry. No broad removal of unrelated CSS based on text matching.
