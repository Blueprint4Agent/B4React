# 메인 페이지 템플릿

[English](../main-page-template.md)

`src/components/layout/MainPageTemplate`은 설정 계열의 메뉴 중심 화면을 위한 배치 컴포넌트입니다.
인증·API·라우팅 상태·저장소를 소유하지 않으며 AppLayout 안에서 사용합니다.
홈은 별도의 [홈 랜딩 계열](page-families.md#홈-랜딩)을 사용합니다.

- `title`, `description`, `icon`: 제목 영역.
- `actions`: 상단 액션. 기존 `Button`, `DropdownMenu` 등을 배치합니다.
- `menuLabel`, `menuItems`: 접근성 이름과 메뉴 목록. 고유 ID, 경로, 제목,
  선택적인 설명·아이콘을 전달합니다. 역할 필터는 페이지에서 처리합니다.
- `menuLayout`: 기본 `list` 또는 반응형 `grid`.
- `children`: 추가 섹션·목록·카드·위젯과 로딩·오류·빈 상태를 배치합니다.

```tsx
<MainPageTemplate
    title="워크스페이스"
    description="오늘의 작업을 시작하세요."
    actions={<Button onClick={createProject}>프로젝트 만들기</Button>}
    menuLabel="워크스페이스 메뉴"
    menuLayout="grid"
    menuItems={items}
>
    <ProjectList />
</MainPageTemplate>
```

위의 `items`, `createProject`, `ProjectList`는 확장 방법을 보여주는 예시이며 기본
제공 기능은 아닙니다. 데이터 요청은 해당 훅·페이지에서 처리하고 서버 권한 검사를
유지하세요. 실제 홈에 가짜 통계를 넣지 않습니다.

개발 쇼케이스는 그리드 메뉴·상단 액션·추가 콘텐츠 배치를 보여줍니다.
템플릿의 설정 셸·헤더·행 토큰을 유지합니다. `contentPosition`은 `before-menu`와 기본값 `after-menu`를 지원합니다.

홈은 소개와 실제 제품 미리보기, 박스 없는 기능 세 그룹, 저장소·가이드 링크, 작은 계정 메뉴로 구성됩니다.
네 개의 텍스트 버튼으로 미리보기를 선택하며 중복 썸네일 이미지는 사용하지 않습니다.
미리보기 상태는 로컬이며 확대창의 Escape 종료·초점 복귀는 공통 Modal을 따릅니다.
이미지는 실제 상태가 아닌 데모 데이터이며 출처는 `public/home-previews/README.md`에 기록합니다.
선택한 앱 셸, 역할별 경로, 비로그인 진입 및 계정 메뉴는 유지합니다.

스크린샷의 계정·결제·상태 값은 데모 데이터이며 실제 정보를 조회하지 않습니다. 관리자 화면 이동은 기존 권한을 따르고 결제 이동은 설정과 로그인 상태를 따릅니다. 상단 버튼은 부드럽게 스크롤하되 동작 줄이기 설정에서는 즉시 이동합니다. 기능 목록은 UI·계정·결제·캐시/실시간·이메일·오브젝트 스토리지·관리/모니터링·배포를 소개하며 현재 활성 상태를 의미하지 않습니다.

후원 옵션은 프론트 환경변수 `VITE_BUY_ME_A_COFFEE_ENABLED=true`, `VITE_BUY_ME_A_COFFEE_URL=https://buymeacoffee.com/yourname`으로 설정하고 다시 빌드합니다. 공개 빌드 시점 값이며 기본값은 꺼짐입니다. 크리에이터 아이디는 영문·숫자·점·밑줄·하이픈을 허용합니다. buymeacoffee.com 또는 www의 HTTPS 프로필 URL만 허용하고 사용자정보·별도 포트·쿼리·프래그먼트는 허용하지 않습니다. 서버 `app_mode=development`에서만 표시하며 운영·미확인·로딩 상태에서는 설정과 무관하게 숨깁니다. 외부 스크립트·iframe·추적 요청은 추가하지 않습니다.

같은 후원 옵션을 사이드바 하단의 프로젝트 링크 아래·프로필 위에도 표시합니다. 접힌 상태는 커피 아이콘과 툴팁, 펼친 상태는 문구를 함께 표시합니다. 홈 후원 영역도 유지하며 두 위치는 같은 URL 검증과 개발 모드 조건을 공유합니다.

홈 후원 링크는 소개 영역 상단의 브랜드 이름 옆에 작은 텍스트와 커피 아이콘으로 표시합니다. 하단의 별도 후원 블록은 사용하지 않습니다.

홈은 프로필 보안, 알림함, 비공개 문의와 실시간 연결(SSE 연결, 선택형 웹소켓 프로바이더)을 소개합니다. 로그인 사용자는 알림함·문의 바로가기를 사용합니다. 쇼케이스는 Blocks 아이콘이며 관리자는 실제 패널만 표시합니다. 문의 데모는 공통 문의 화면에 번역된 예시 데이터만 표시하며 실제 문의 API 조회·변경은 실행하지 않습니다.
