# 결제 설정과 플랜 선택

[English](../billing.md)

프로필 메뉴의 **플랜 업그레이드**에서 지연 로딩되는 `/plans` 화면으로 이동합니다.
Free·월간·연간 선택과 원화/달러 표시 통화를 URL에 보관합니다. 템플릿 예시 가격은
월간 ₩3,990 / US$3.99, 연간 ₩39,900 / US$39.99입니다. 환율 환산이나 실제 Stripe
Price가 아닙니다. 구독·권한 부여·거래 내역·청구 주소 편집·구독 취소는 아직 제공하지
않습니다. Free 표시는 카드 등록용 템플릿의 기본값이며 서버에서 조회한 구독 상태가
아닙니다. 후속 구독 구현 시 이 표시를 유료 권한 판정에 사용하지 마세요.

유료 플랜 선택 후 `/settings?section=billing&plan=monthly` 또는 annual로 이동합니다.
로그인/부트스트랩 사용자는 설정 사이드바에서도 결제를 열 수 있습니다. 비로그인
사용자는 일반 설정과 플랜 보기·로그인 안내만 이용합니다. 플랜 선택 자체는 구매나
구독 변경이 아닙니다. 비즈니스/팀 플랜은 이번 범위에 포함하지 않습니다.

페이지가 `useBilling`을 소유하고 기존 타입 기반 `useBillingApi`를 호출합니다.
설정 조회 뒤 카드·Link 목록을 각각 조회하고 커서 기반 더 보기를 제공합니다.
로딩·비활성·빈 목록·실패/재시도·테스트 모드·데스크톱 연결 끊김을 구분합니다.
등록은 해당 계정 화면에서 실패한 재시도에 같은 UUID를 사용하고 중복 클릭을 막습니다.
이동 주소는 HTTPS `checkout.stripe.com`만 허용하며 카드 정보나 인증 정보는 저장하지 않습니다.

배포 프론트 주소에 `/settings?billing_setup={CHECKOUT_SESSION_ID}`와
`/settings?billing_setup=cancelled`를 Stripe 반환 URL로 설정합니다. 기존 기본 경로도
section 값 없이 자동으로 결제 화면을 엽니다. 반환된 ID로 서버 상태를 조회하여
`registered=true`일 때만 등록 완료를 표시합니다. 쿼리·complete 상태·플랜 선택만으로
성공을 판단하지 않습니다. 다시 불러오기로 미완료/실패 확인을 재시도합니다.
브라우저의 동일 앱 주소/로그인 세션 복귀를 지원하며 네이티브 외부 브라우저와 딥링크
등록 복귀는 아직 구현·검증하지 않았습니다.

계정별 페이지 key와 요청 세대를 사용하여 계정 전환/언마운트 뒤의 오래된 응답·이동을
무시합니다. 브라우저 focus/online과 데스크톱 연결 복구 시 갱신합니다. Billing SSE는
현재 계약에 없으므로 추가하지 않습니다. 다른 설정이나 플랜 가격만 볼 때는 결제 API를
호출하지 않습니다. UUID는 메모리에만 있어 실패한 요청 중 페이지를 떠나거나 새로고침하면
새 작업으로 취급합니다. 영구 중복 방지 보장이 아니며 서버의 고객 예약 보호는 유지됩니다.

기존 Button·PrimaryCard·InlineMessage와 프로필/사이드바를 재사용하며 스타일은
app.css에 둡니다. 전역 스토어나 공통 컨트롤 API를 추가하지 않습니다. 작은 플랜 카드
3개는 URL/언어/통화 변경이 주된 갱신 원인이므로 memo를 적용하지 않습니다. 훅 요청 수,
계정 격리, 브라우저 및 운영 빌드 라우트 테스트로 흐름을 확인합니다.
